**Where the work lands.** The repo has no shared test-helper module under tests/ (tests/e2e holds exactly the two spec files), and foundation.spec.ts already has module-scope, JSDoc'd helpers typed against `Page` (`blockAudio`, `disableWebgl`, `watchErrors`) — the new guard follows that pattern. Config projects are named `chrome` and `firefox`; `verify` chains lint → typecheck → vitest → build → Playwright → size, giving 24 e2e tests (12 × 2 projects).

**Decisions and changes**

- Shared-string mechanics: R5 forbids a third file, and the acceptance command's findstr evidence needs the literal marker to live in both spec files, so the shared reason string is one named constant — identical name, identical value — declared at module scope in each in-scope spec file and used by all six guards. Importing one spec file from another was rejected: it would drop the literal from tooling.spec.ts and risks Playwright's per-file test collection.
- The browser name enters the reason via `test.info().project.name` (`chrome` / `firefox`), read inside the guard, so no test signature changes and R4 holds. Verified against the installed @playwright/test 1.56 types (`TestInfo.project: FullProject`, `FullProject.name: string`).

- Current position: two earlier rounds failed the fidelity gate on one point only — they described the reason as per-file copies. This plan restates R2 as the goal words it and implements one shared string; nothing else differs from the accepted constraint set.

In tests/e2e/foundation.spec.ts, declare at module scope beside the existing helpers (`Page` is already imported there):

```ts
/** Shared skip reason for the WebGL-dependent scenarios: the gpu-less driver-exhaustion marker plus the browser name. */
const WEBGL_SKIP_REASON = (browser: string): string =>
  `FEATURE_FAILURE_WEBGL_EXHAUSTED_DRIVERS: ${browser} cannot create a WebGL 2 context`;

/** Skips the running test unless this browser really provides WebGL 2. */
async function requireWebgl2(page: Page): Promise<void> {
  const ok = await page.evaluate(() => !!document.createElement('canvas').getContext('webgl2'));
  test.skip(!ok, WEBGL_SKIP_REASON(test.info().project.name));
}
```
